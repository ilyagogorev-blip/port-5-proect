# 🦷 Кейс: Telegram-бот для стоматологии «СтомаПро»

Workflow ID: `F0qz2rCeBWzwuWrE` | Статус: ✅ Активен

Бот-ассистент Ева — виртуальный администратор стоматологической клиники. Принимает обращения через Telegram, консультирует по услугам и ценам, собирает заявку, уведомляет администратора.

---

## Архитектура (14 нод)

```
Telegram Trigger (message + callback_query)
    ↓
Normalize Input — извлекает chat_id, user_text, callback_query_id.
                  Маппит короткие коды кнопок в полный текст
    ↓
Is Start? (user_text === '/start')
  ✅ ДА → Send Welcome (HTTP Request — приветствие + 5 inline-кнопок)
  ❌ НЕТ → Answer Callback (HTTP, onError: continueRegularOutput)
           → Restore Context (Code — возвращает данные из Normalize Input)
           → AI Agent (Ева)
           → Format Response (Code — парсит JSON от AI, разделяет клиент/админ)
           → Is New Record? (содержит "НОВАЯ ЗАПИСЬ"?)
               ✅ ДА → Send to Client + Send to Admin
               ❌ НЕТ → Send Response (обычный ответ с кнопками)
```

---

## Inline-кнопки

### Welcome-экран (`/start`)
| Кнопка | callback_data | Разворачивается в |
|---|---|---|
| 🦷 Записаться на приём | `record` | «Хочу записаться на приём к стоматологу» |
| 💰 Стоимость услуг | `prices` | «Хочу узнать стоимость услуг» |
| 🚨 Острая боль — срочно! | `urgent` | «У меня острая боль, нужна срочная помощь» |
| 🧹 Чистка и профилактика | `cleaning` | «Интересует профессиональная чистка зубов» |
| ✍️ Напишу сам | `freewrite` | «Хочу написать свой вопрос» |

> Короткие коды нужны из-за лимита Telegram: `callback_data` ≤ 64 байта.

### Контекстные кнопки (AI генерирует динамически)
AI Agent всегда возвращает JSON `{"text": "...", "buttons": [[...]]}`. `Format Response` парсит его с 4-уровневым fallback-парсером:
- **Перечисляет услуги** → кнопка на каждый вариант + «✍️ Другое»
- **Предлагает слоты** → кнопка на каждый слот + «✍️ Другое время»
- **Подтверждение** → «✅ Подтвердить» / «✏️ Изменить»
- **Просит имя/телефон** → кнопок нет

## Известные проблемы и решения

| Проблема | Причина | Решение |
|---|---|---|
| Бот Job Hunter шлёт сообщения стоматологии | Оба воркфлоу использовали `TELEGRAM_BOT_TOKEN` | Отдельная переменная `TELEGRAM_STOM_TOKEN` |
| `BUTTON_DATA_INVALID` | callback_data > 64 байт (русский текст) | Короткие коды: `record`, `prices`, `urgent` и т.д. |
| JSON-артефакты в сообщениях | AI иногда не оборачивает ответ в JSON | Format Response: 4-уровневый парсер + fallback на сырой текст |
| Кнопки не появляются при /start | IF нода: boolean-сравнение не работало | Строковое сравнение `user_text === '/start'` |
| Брендинг «sent automatically with n8n» | Telegram-нода в Community Edition | HTTP Request вместо Telegram-ноды |
| Заявка слалась после каждого сообщения | Is New Record? не было | Добавлена проверка на «НОВАЯ ЗАПИСЬ» в тексте |

## Адаптация под другую клинику

1. **Название** — в `systemMessage` заменить «СтомаПро»
2. **Услуги и цены** — обновить список в `systemMessage` ноды `AI Agent`
3. **Кнопки welcome-экрана** — в ноде `Send Welcome` обновить `jsonBody`
4. **Имя бота** — поменять «Ева» в `systemMessage`
5. **Chat_id администратора** — в `Format Response` заменить `ADMIN_CHAT_ID`
