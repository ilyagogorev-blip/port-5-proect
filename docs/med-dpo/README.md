# 🏥 МЕД ДПО демо

Workflow ID: `jrnksVhHbVUMLql7` | Статус: ✅ Активен (нужна Telegram credential в триггере)

Telegram-бот Алина — консультант компании по дополнительному профессиональному образованию медработников. Квалифицирует клиентов, собирает заявку и уведомляет специалиста Алексея.

---

## Архитектура (7 нод)

```
Telegram Trigger
    ↓
AI Agent (Алина) + OpenAI Chat Model + Simple Memory
    ↓
Send to Client (HTTP Request — $env.TELEGRAM_MED_TOKEN, без брендинга)
    ↓
If (содержит "НОВАЯ ЗАЯВКА"?)
  ✅ ДА → Send to Admin (HTTP Request — отправка на 586613159)
  ❌ НЕТ → конец (обычный ответ уже отправлен)
```

2. Открыть ноду `Telegram Trigger` → выбрать этот credential
