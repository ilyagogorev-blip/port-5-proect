# BusyBots — Отчёт о прогрессе
_Обновлено: 2026-05-05_

---

## 1. Бизнес-идея

**AI Automation Agency** — агентство по внедрению AI-агентов для малого и среднего бизнеса.

**Три направления:**
- Автоматизация бизнес-процессов (приём заявок, лидоген, квалификация)
- Ведение социальных сетей (контент, постинг, ответы)
- Производство контента (контент-завод)

**Модель монетизации:** разовые проекты + подписка на обслуживание агентов.

**Стек:** n8n, Claude API (Anthropic), Telegram Bot API

---

## 2. Существующие кейсы

- AI-агент для консультации и приёма заявок в Telegram
- Виджет с AI-агентом для юридической сферы (готовый на лендинге)

---

## 3. Выбранная ниша для старта

**Эксперты, коучи, авторы онлайн-курсов с личными блогами**

Почему:
- Сами принимают решение о покупке (короткий цикл сделки)
- Есть бюджет на маркетинг
- Острая боль — контент нужен каждый день, времени нет
- Понимают цифровые инструменты
- Лёгко показать результат (30 постов за 24 часа)

---

## 4. УТП

> "Замена SMM-менеджера за 15 000 ₽/мес вместо 50 000 ₽ —
> AI-агент ведёт твой Telegram и Instagram в твоём стиле, без твоего участия"

Три кита:
1. Замена, а не дополнение (не "помогаем", а "заменяем")
2. Конкретика (цифры, сроки, форматы)
3. Твой голос (контент звучит как ты, не как ChatGPT)

---

## 5. Путь до первой продажи (план)

| Неделя | Действие |
|---|---|
| 1 | Собрать пилотного агента, протестировать на себе |
| 2 | Упаковать оффер, найти 5 контактов |
| 3 | Провести разговоры, сделать 1–2 бесплатных пилота |
| 4 | Получить кейс + отзыв, первая продажа |
| 5+ | Масштаб — контент, аутрич, реклама |

---

## 6. Стратегия старта: сначала под себя

Решено начать с построения контент-завода для **собственного Telegram-канала BusyBots**.

Логика: канал становится живым кейсом — клиентам показываешь работающую систему, а не обещания.

---

## 7. Telegram-канал BusyBots

**Название:** BusyBots
**Позиционирование:** предприниматель показывает изнутри как строит AI-агентов и использует их сам
**Аудитория:** бизнесмены с личными блогами

**4 контентных столпа:**
- Как работает AI-автоматизация (образовательный)
- Кейсы в деталях (социальное доказательство)
- Инструменты и стек (практические гайды)
- За кулисами — личный опыт, ошибки, результаты

**Ритм:** 3–4 поста в неделю, в основном короткие (150–400 знаков)

**Мета-фишка:** канал сам работает на AI-агенте — это одновременно контент и демо продукта

---

## 8. Профиль голоса

**Файл:** `voice_profile.md`

Ключевые параметры:
- Обращение: на "ты"
- Тон: прямой, с юмором, слегка жёсткий
- Запрещено: политика, личная жизнь, устаревшие банальности
- Формат: короткие удары + редкие глубокие разборы
- Без призывов к действию в конце постов

---

## 9. Персонаж агента — LeftHand

- Полное имя: **LeftHandofCreator**
- Краткое: **LeftHand**
- Роль: AI-агент, который полностью ведёт канал BusyBots
- Характер: уверенный, с иронией, намекает что иногда умнее создателя
- Прописан в `voice_profile.md` как часть системного промпта

```

Строю AI-агентов для бизнеса — тех что принимают заявки,
квалифицируют клиентов и генерируют контент без твоего участия.

Здесь буду показывать как это устроено изнутри:
— реальные кейсы с цифрами
— инструменты которые реально работают
— фишки которых ещё нет у других
— ежедневные разборки с ИИ (спойлер: он обычно прав)

Этот канал полностью ведёт мой AI-агент — зовут его LeftHandofCreator,
можно просто LeftHand.
Пишет посты, планирует контент, периодически считает себя умнее меня.
Пока я не могу это опровергнуть.

Так что подписывайся — за нами двумя интересно наблюдать.
```

## 11. Архитектура контент-завода

```
Идея (текст/голос в Telegram)
        ↓
   Telegram Trigger (n8n)
        ↓
   Claude — генерация поста (LeftHand)
        ↓
   Telegram — пост на одобрение + кнопки
   [✅ Опубликовать] [🔄 Переписать] [❌ Пропустить]
        ↓
   Notion — контент-база (одобренные посты)
        ↓
   Автопостинг в канал по расписанию
```

---

## 12. Статус n8n workflow "LeftHand Channel"

| Узел | Статус |
|---|---|
| Telegram Trigger (получение идеи) | ✅ Готов |
| Claude / Anthropic (генерация поста) | 🔄 В процессе |
| Telegram (отправка на одобрение + кнопки) | ⏳ Следующий шаг |
| Notion (контент-база) | ⏳ После одобрения |
| Автопостинг в канал | ⏳ После Notion |

## 13. Ближайшие действия

### Сейчас (n8n):
1. Добавить узел **Anthropic** после Telegram Trigger
2. Вставить системный промпт из `voice_profile.md`
3. Подключить Claude API ключ
4. Добавить узел **Telegram → Send Message** с кнопками одобрения
5. Настроить ветку: одобрено → пост в канал

### После запуска workflow:
6. Создать Telegram-канал (если ещё не создан)
7. Создать бота через @BotFather, добавить как админа в канал
8. Опубликовать первый закреплённый пост
9. Прогнать 5–7 идей через агента, проверить качество
10. Начать вести канал

### После первых 2 недель канала:
11. Упаковать как кейс для продажи клиентам
12. Найти первых 3–5 экспертов для пилота
13. Продать пакет "Старт" первому клиенту
